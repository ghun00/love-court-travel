# 다낭 테니스 트립 영상

이 폴더에 영상을 넣으면 `/trips/danang` 상세 페이지의 "제공 사항" 아래에 세로 영상 카드로 자동 노출됩니다.

- 형식: **mp4 (H.264)** 권장 · webm 가능 (아이폰 .mov/HEVC는 크롬에서 안 나올 수 있어 mp4로 변환)
- 비율: 세로 9:16 (예: 1080×1920)
- 순서: 파일명 순 → `01.mp4`, `02.mp4`, `03.mp4` …
- 표지(선택): 영상과 같은 이름의 이미지 → `01.jpg` / `01.webp`. 없으면 영상 첫 프레임이 표지
- 용량: 한 개당 10MB 이하 권장 (긴 영상은 15~30초로 잘라서)

다른 트립도 같은 방식: `src/assets/reels/<트립 id>/` (예: `hakone`)
